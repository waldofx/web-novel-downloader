Web novel downloader

Saves a novel and its chapters into a folder you own, illustrations included, and can write an EPUB, plain text or Markdown beside them.

The novel

Any address into a work: a table of contents, a chapter, or a series.

The novel is written straight into this folder — the same folder nvd download --out names. Choosing it again resumes and fetches only what is missing.
