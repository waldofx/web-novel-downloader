# Documentation

Two tiers, two audiences. Pick the one you are in.

| If you want to… | Read |
| --- | --- |
| use the tool | [guide/](guide/) |
| understand or change the code | [engineering/](engineering/) |
| know why something is weird | [engineering/gotchas.md](engineering/gotchas.md) |

**The guide** is for someone who just wants their novel offline. It avoids
jargon and explains only what is needed to run things.

**The engineering tier** is the deep dive: architecture, the on-disk format and
its invariants, why decisions were made, and how to test. It is written for
developers and AI agents working on the code. Its **gotchas log** is the most
valuable page here — every surprise that cost someone time is recorded so it
never costs time twice.

The root [README.md](../README.md) is the front door.
[CONTRIBUTING.md](../CONTRIBUTING.md) and [AGENTS.md](../AGENTS.md) cover how
work is done in this repository.
